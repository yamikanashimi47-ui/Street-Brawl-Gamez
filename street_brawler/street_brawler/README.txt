STREET BRAWLER  (Godot 4.3+)
Open Godot -> Import -> select project.godot -> press F5.

P1: A/D move, W jump, F punch, G kick
P2: Left/Right move, Up jump, K punch, L kick
Hold the direction AWAY from the enemy to block.

COMBOS: land a hit, then press the next button right away.
  ONE-TWO       punch, punch
  KICK RUSH     kick, kick
  TRIPLE STRIKE punch, punch, kick
  KENJI FURY    punch, punch, kick, kick  (launcher)

PRACTICE MODE: R = reset, B = dummy blocks on/off.
ESC or P = pause (Resume / Combo List / Restart / Quit).
